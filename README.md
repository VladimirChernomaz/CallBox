# CallBox

Личный голосовой звонок между двумя телефонами через интернет, в обход блокировок обычных мессенджеров —
трафик идёт через TURN-ретранслятор Metered на порту 443, маскируясь под обычный HTTPS.

Своего сервера нет — используется бесплатный сервис **Metered Realtime Messaging** только для того,
чтобы два телефона нашли друг друга, плюс встроенный TURN для самого голоса.

Ключ и название комнаты не зашиты в код — каждая пара пользователей вводит свои прямо в приложении
при первом запуске. Значит, один и тот же APK можно передать кому угодно — приложение подстроится
под того, кто его установит.

## Сборка
Автоматически через GitHub Actions при коммите в `main`. Готовый APK — вкладка **Actions** → последний
зелёный запуск → **Artifacts**.

## Как пользоваться
1. На dashboard.metered.ca создайте Publishable key (Dashboard → Realtime Messaging → API Keys,
   галочка **Send** обязательна).
2. При первом запуске приложение попросит этот ключ и название «комнаты» — придумайте что угодно
   непубличное, известное только вам двоим (например `ivan-petya-x7q2`).
3. Оба человека ставят приложение и вводят **одинаковые** ключ и название комнаты.
4. Когда статус сменится на «Собеседник на связи» — любой жмёт «📞 Позвонить».
5. Второй видит «Входящий звонок» → «✅ Принять».

Сменить ключ или комнату позже можно кнопкой ⚙ на главном экране.
